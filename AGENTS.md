# LPX design canon

## Background imagery — all current and future public pages

The homepage background image, `images/lpx_bg.jpg`, is the canonical background for every LPX public-site page. Use it when creating any future page and preserve its use when editing existing pages.

- Use the supplied image unchanged. Do not regenerate, recolor, destructively crop, or replace the asset.
- Reuse the homepage's cinematic background treatment. CSS darkening overlays, responsive background sizing, and section-specific positioning are allowed to preserve text readability and reveal the vinyl, turntable, and world imagery appropriately.
- Do not introduce another image as the site background or create competing decorative artwork.
- Use relative image URLs appropriate to the page or stylesheet location.
- This rule concerns the site background; genuine album/project artwork may still appear as content.

The homepage, Archive, and For Artists page already use this image. Keep the shared black, warm ivory, and restrained gold visual language consistent across future pages.
